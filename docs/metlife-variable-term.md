# 메트라이프 변액리치정기보험 · 상담 예시용 추정형 v0.4

이 도구는 가입설계 전 상담을 위한 **확정되지 않은 추정 예시**다. 보험사 견적, 계리 산출방법서의 복원, 계약 보증, 전환 승낙을 의미하지 않는다. 전연령 보험료표·산출방법서 없이, 제공된 공식 예시의 현금흐름을 설명하는 합산 비용 모델을 구성했다. 같은 관측값에 맞는 다른 비용 조합이 존재하므로 실제 위험보험료와 사업비를 각각 식별할 수 없다.

## 고객 입력과 자동 계산

출생연도·성별·일반/간편·월 기본보험료 또는 가입금액·전환시점(7년 이후 정수)·추가납입(0/50/100%)·전환 전후 연 수익률(-1~20%)·전환 후 가입금액만 입력한다. 숫자와 슬라이더는 동기화되며 즉시 계산한다. 비용·적립액을 고객에게 직접 입력하게 하지 않는다.

- 전환 전: 전기납 / 90세 만기. 출생연도는 2026년 기준 연나이 예시이며 실제 보험나이가 아니다.
- 전환 후: 적립형 종신 계약을 90세까지만 예시한다. 초회 최저보험료를 별도 납입한 뒤 정기보험료는 0원이다.
- 각 경과연도는 연말 기준이다. 선택한 전환연도의 행은 전환 직전 적립금에 초회보험료를 더한 **전환 직후**이며, 그다음 행부터 전환 후 1년이 지난 값이다.
- 7·8·9·10년 비교는 각 시점의 전환 직전 적립금 및 전환 후 10년이 지난 환급금을 표시한다. 기본은 각 시점의 최저 가입금액이며, 사용자가 전환 후 가입금액을 수정하면 동일 금액을 적용하고 각 한도를 재검사한다.
- 사망보험금과 해약환급금은 서로 다른 지급사유에 따른 금액이며 합산 수령액이 아니다. 세전 예시이며 대출·중도인출·특약·납입면제·부분전환·플러스기간은 계산하지 않는다.

## 1. 보험료와 가입금액 연결

신상품 리플렛 PDF 5쪽의 90세만기·전기납·가입금액 1억원당 예시보험료를 사용한다. 일반 남녀 20/30/40/50/60/70세, 간편 남녀 30/40/50/60/70세가 기준점이다.

기준점 사이는 보험료의 로그값을 선형 보간한다. 기준점 밖의 허용 가입나이는 양 끝 두 기준점의 기울기로 외삽한다(일반 15~19세, 간편 71~75세). 실제 가입설계의 연령별 곡선, 금액별 할인·할증, 절사 규칙을 복원한 것이 아니다.

보험료 예산 입력 시 `가입금액 = 보험료 / 1억원당 보험료 × 1억원`을 100만원 단위로 내린다. 입력 예산과 실제 보험사 보험료는 일치하지 않을 수 있다. 가입금액 입력 시 같은 참고 요율로 월보험료를 반대로 계산한다. 일반 가입금액 1천만~50억원, 간편 1천만~20억원 범위를 적용한다. 특약 없는 화면의 월 기본보험료는 8만원 이상으로 제한한다.

보간에 사용하지 않은 41세 남성의 차년도 보험료 1억원당 116,800원과 대조하면 추정 117,033원, 차이 약 +0.20%다. 한 개 점의 대조이며 전연령 정확도를 뜻하지 않는다.

## 2. 보장형 적립금과 환급금 역산

`metlife/fixtures.json`의 40세 남녀·10억원 기본납입, 40세 남성 추가납입 100% 예시를 사용한다. -1%, 3.75%는 보정에 사용하고 **2.5%는 보정에서 제외**해 대조한다. 만원 미만 절사된 표시값이므로 정확한 원 단위 기초값은 알 수 없다.

월별로 기본·추가 적립계정을 갱신한다. 기본보험료에 기간별 합산 공제 비율(1~7년, 8~10년, 11년 이후)을 적용하고, 나이에 따른 금액 비례 합산 비용·잔액 비례 합산 비용을 차감한다. 나이별 비용은 양수 노드의 로그 보간이며, 40세 미만은 첫 두 노드 기울기를 연장한다. 이들 계수는 **실제 사망률이나 사업비율이 아니다**.

추가납입은 첫 달분을 두 번째 달에 함께 납입하는 원자료 예시를 적용한다. 추가납입 수수료는 상품 설명의 0원을 따른다. 사망위험금 근사값은 `max(가입금액 + 누적추가납입 - 합산적립금, 0)`이다. 보장형 보증비용은 가입금액의 연 0.011%/12를 별도 반영한다. 월 비용 차감 후 월 유효복리 수익률을 적용한다.

초기 환급금과 적립금의 차이를 설명하기 위해 7년간 직선 감소하는 미상각 공제 대용 항을 사용한다. 초기에는 기본 적립금에서 이 항을 차감한 금액과 추가 적립금으로 환급금을 근사하고, 7년 이후에는 환급금과 적립금이 같다고 **모델상 가정**한다. 보험사 적립액이나 실제 해약공제표를 확인한 결과가 아니다. 전환 시점에 이 추정 적립금을 사용하며 공식 해약환급금을 공식 계약자적립액이라고 바꾸어 표시하지 않는다.

보장형 사망보험금은 `max(가입금액 + 누적추가납입, 적립금×105%, 기납입보험료)`로 근사한다. 간편형 첫 2년의 재해 이외 사망은 가입금액 부분의 50% 감액을 가정한다. 재해 사망을 별도 시뮬레이션하지 않는다.

## 3. 적립형 전환과 무납입 예시

공시 약관·사업방법서에 따른 주요 조건을 적용한다.

- 가입 후 7년 이상, 전환 나이 80세 이하, 기본만기 전. 실제 효력 발생일·승낙은 별도다.
- 추정 적립금이 `max(전환 전 기납입보험료×70%, 100만원)` 이상인 경우에만 후속 계산한다. 실제 심사·납입면제 미적용·계약 상태는 별도 확인해야 한다.
- 초회 최저 기본보험료는 `max(10만원, 기납입보험료×0.5%)`를 1만원 단위로 올린 값이다. 전환 전 가입금액의 2% 이하인지 검사한다.
- 전환 후 가입금액은 초회 기본보험료 50배 이상을 100만원 단위로 올리고, 전환 전 가입금액 이하로 설정한다. 기본값은 최저다.
- 초회 납입액을 실제 누적 납입액에 더한다. 이후 정기납입·추가납입은 0원이다.

적립형 비용은 제공된 7년 전환 설계서(남성 추가납입 100%, 여성 기본납입, 전환 후 가입금액 10억원)의 표를 이용해 별도로 보정한다. 나이·선택 가입금액 비례 합산 비용과 잔액 비례 합산 비용을 사용하며, 알려진 연 0.15% 보증비용을 따로 반영한다. 추가 잔액 비례 계수는 표를 설명하는 **미확인 합산 비용의 대용값**이며 펀드 운용보수를 다시 차감하는 항목이라고 해석하지 않는다. 입력 수익률은 펀드 기준가 기준이며 별도 고정 펀드보수는 중복 차감하지 않는다.

납입 중지 후 사망보험금은 `max(전환 후 가입금액+적립금, 전환 전 기납입보험료+초회 납입액)`으로 근사한다. 최소보증액이 더 큰 경우를 위해 비용에 사용하는 위험금은 `max(선택 가입금액, 누적 납입액-적립금)`으로 근사한다. 별도 해약공제 없이 적립금=환급금으로 예시한다.

**초회 납입 시 별도 공제는 자료에서 식별하지 못해 전액 투입을 가정한다.** 원자료의 전환 예시에는 초회보험료가 기재되지만 표시 납입누계에는 합산되지 않는 차이가 있다. 보정은 원자료의 0년납·표시누계 기준으로 하고, 고객 예시에서는 의무 초회보험료를 분명하게 추가한다. 회사의 실제 초회 공제·집계 시점·일별 절사에 따라 차이가 생길 수 있다.

월 비용을 감당하지 못하면 해당 시점 이후 사망보험금·환급금·환급률을 모두 산출 제외로 표시한다. 이는 실제 실효일을 단정하는 처리가 아니며, 납입최고·유예·보증 유지 조건은 실제 약관과 계약 상태 확인이 필요하다. 원자료의 0원 환급금 행은 음수 잠재잔액의 검열 관측값으로 처리하며 그 이후 사망보험금을 보장한다고 확대 해석하지 않는다.

## 4. 일반형 외 확장 추정

- 다른 가입나이: 참고 보험료를 바꾸고 도달나이의 합산 비용을 적용한다. 가입연령별 사업비 차이를 검증하지 못했다.
- 다른 가입금액: 금액 비례 근사다. 고정 관리비·금액대별 할인 등이 별도로 식별되지 않았다. 특히 전환 후 최저 가입금액은 보정 사례의 10억원보다 작아 오차가 클 수 있다.
- 추가납입 50%·여성 추가납입: 기존 합산 모델의 현금흐름을 확장했다. 전용 설계서로 검증한 결과가 아니다.
- 간편형: 보험료는 간편형의 별도 기준점을 사용한다. 금액 비례 비용은 가입나이의 `간편 예시보험료 / 일반 예시보험료`를 곱하는 임시 대용이다. 간편형 환급금 표를 보정한 결과가 아니며 전용 가입설계서가 오면 교체한다.
- 전환 8년 이후·수익률 3.75% 초과: 시뮬레이션 확장이다. 20%는 조절 가능한 시나리오의 상한이며 권유·예측·보장 수익률이 아니다.

현재 38개 Node 테스트: 공식 조회 22개와 고객 추정형 16개. 보험료 기준점·보간·독립 41세 대조·2.5% 제외 검증·전환 최소보험료·무납입 현금흐름·전환 거절·비용 부족·가입금액 한도·음수/0/20% 수익률·합산 비용 민감도·단일 HTML 빌드를 포함한다.

## 빌드와 보정 재현

배포 HTML은 순수 HTML/CSS/JS 단일 파일이며 외부 자산·계산 서버·npm 의존성이 없다. 원본은 `metlife/`, 결과는 `metlife-variable-term.html`이다. 입력은 브라우저 메모리에만 유지하고 외부로 전송하지 않는다.

```sh
node scripts/build-metlife.mjs
node --test tests/*.test.cjs
node scripts/verify-metlife-calibration.cjs --write
```

보정 재실행은 개발 환경에 NumPy·SciPy가 필요하다. 고객 브라우저에는 필요하지 않다. 수치 최적화 라이브러리 버전에 따라 마지막 자릿수는 달라질 수 있다.

```sh
python scripts/calibrate-metlife.py
node scripts/build-metlife.mjs
node scripts/verify-metlife-calibration.cjs --write
node --test tests/*.test.cjs
```

## 기존 공식 조회·수동 연구 도구

v0.1~0.3의 공식 표 조회와 명시 비용 입력 연구 도구는 하단 접힌 내부 검토 영역에 유지한다. 공식 조회는 표 사이를 보간하지 않고 공식 표시값을 그대로 표시하며, 고객 추정 화면의 결과와 구분한다. 환급률은 원자료 값을 사용하고 누적 납입액은 실제 월납 횟수로 계산한다. CSV와 기존 전환 적립액 수동 입력 검토는 이 영역의 기능이다. 고객 추정 화면에는 미확인 비용 직접입력란이 없다.
