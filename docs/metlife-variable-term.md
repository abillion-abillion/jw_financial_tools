# 메트라이프 변액리치정기보험 초안

## 범위

`metlife-variable-term.html`은 **공식 설계 예시 조회 도구**입니다. 보험사의 위험률·사업비를 재현하는 범용 계리 엔진이 아닙니다. 기존 미래에셋 변액연금 도구와 분리된 새 파일이며, 기존 계산식은 변경하지 않습니다.

- 상품 버전: 2026-10-20, 자료 확인 및 설계일: 2026-10-28.
- 일반가입형, 가입나이 40세, 가입금액 10억 원, 90세 만기, 전기납, 특약 없음.
- 골드투자형 20% + 미국주식형3호 80%.
- 남녀 기본납입, 남성 기본 + 추가납입 100%.
- 각 29개 시점 × 3개 수익률(-1%, 2.5%, 3.75%) = 261개 환급금 관측값.
- 인출·감액·납입면제·전환 이력이 없는 원자료 계약을 가정합니다.
- 여성 추가납입·임의 조건·관측점 사이 보간·50년 만기/플러스기간 금액은 제공하지 않습니다.

## 사용

루트의 `metlife-variable-term.html`을 브라우저에서 열면 됩니다. 별도 설치·빌드·네트워크 연결이 필요 없습니다. GitHub Pages에서도 같은 파일을 제공할 수 있습니다.

입력 변경 시 표·카드·그래프·CSV는 같은 모델을 사용합니다. 해시 URL은 성별·납입방식·수익률·경과기간만 유지하며, 직접 입력한 적립액은 저장하지 않습니다. CSV는 선택한 수익률의 모든 시점을 BOM을 포함한 UTF-8로 저장합니다. `인쇄 / PDF`는 브라우저 인쇄 기능이며 인쇄창에서 PDF로 저장할 수 있습니다.

## 개발

```sh
node scripts/build-metlife.mjs
node --test tests/metlife.test.cjs
```

빌드는 Node 기본 모듈만 사용합니다. 원본은 `metlife/`에 있으며 빌드 결과인 단일 HTML도 커밋합니다. 별도 npm 의존성을 추가하지 않습니다. 테스트는 생성된 HTML에 동일한 데이터·모델·앱이 포함되는지도 확인합니다.

숫자 재추출은 원본 PDF를 가진 로컬 환경에서 실행합니다. `pdftotext`와 표준 Python이 필요합니다.

```sh
python scripts/extract-metlife-fixtures.py --male '/path/40세 남자.pdf' --female '/path/40세 여.pdf'
node scripts/build-metlife.mjs
node --test tests/metlife.test.cjs
```

추출기는 계약자 이름·연락처 등 식별정보를 추출하지 않습니다. 고객 관련 원문 PDF를 저장소에 올리지 마십시오. fixtures에는 자료 제목·페이지·파일 SHA-256·숫자 표만 포함됩니다. 페이지 위치나 표 구조가 바뀌면 행 수 검사에 실패하므로 재검토가 필요합니다.

## 수치 처리

1. 환급금·기본납입 사망보험금은 원자료의 만 원 미만 절사 표시값을 그대로 보관합니다. 원 단위 정확한 보험사 산출액은 아닙니다.
2. 환급률은 원자료의 표시값을 사용합니다. 절사된 환급금 ÷ 절사된 납입누계로 다시 계산하지 않습니다.
3. 실제 납입누계는 월보험료 × 납입횟수입니다. 원자료에서 절사된 납입누계는 다른 필드로 남깁니다.
4. 남성 추가납입은 2개월차에 첫 달분을 포함하고 이후 매월 같은 금액을 납입한 원자료 가정입니다. 조회가 가능한 최초 시점은 3개월입니다.
5. 추가납입 사례의 실제 사망보험금 표가 없으므로, 약관상 최저사망보험금 `max(가입금액 + 누적추가납입액, 기납입보험료)`만 산출합니다. 적립액×105%가 더 큰 경우의 실제 사망보험금으로 오인하지 않도록 별도 표시합니다.
6. 환급금에는 이미 반영된 보증비용·사업비 등을 다시 차감하지 않습니다. 펀드 기준가에 반영된 운용보수도 다시 빼지 않습니다.
7. 그래프의 환급금은 관측점만 표시합니다. 관측점 사이의 환급금은 계산하지 않습니다. 100% 도달 시점도 “수록 시점 중 처음”으로만 표시합니다.
8. 0%는 공식 수익률 표에 없어 명시적으로 거부합니다. 기본값으로 대체하거나 음수 수익률을 0%로 바꾸지 않습니다.

| 남성 기본납입 | 136,320,000원 | 113,330,000원 | 83.14% |

## 적립형 전환 체크의 한계

선택한 예시 시점의 기납입보험료를 이용해 `max(기납입보험료×70%, 100만원)`을 구합니다. 별도로 입력한 **계약자적립액**을 비교하며, 해약환급금을 적립액으로 대체하지 않습니다. 7년 경과·전환나이·납입면제 미적용 확인도 필요합니다. 조건이 바뀌면 직접 입력한 적립액과 확인란을 초기화해 다른 계약에 잘못 재사용하지 않습니다.

이 결과는 주요 요건의 조건부 확인일 뿐 전환 승인이나 전환 후 유지가능성 판정이 아닙니다. 적립형 전환 시 보험료·가입금액 범위, 일부전환, 피보험자 교체, 심사, 실제 효력발생일, 후속 비용은 별도입니다. 원자료에서 전환초회보험료와 누계 집계범위도 추가 확인해야 합니다.

후속 인출 엔진을 만들 때는 공식 약관 제47조를 적용합니다. 적립형 인출 후 잔액 기준은 연간 기본보험료와 500만 원 중 **작은 금액**입니다. 일부 교육자료의 MAX 표기를 사용하지 않습니다.

## 다음 계리 구현에 필요한 자료

- 성별·연령·가입형·만기·가입금액별 기본보험료 요율.
- 연령별 위험보험료(납입면제보험료 포함), 위험보험금 계산식.
- 계약체결비·관리비의 경과기간별 표와 계정별 공제 규칙.
- 미상각 신계약비/해약공제 및 일수·이체·절사 규칙.
- 적립형·플러스기간·종신/연금/달러 전환의 실제 산출계수.

이 자료를 확보하기 전에는 기존 미래에셋 사업비, 임의 사망률 또는 역산 보정계수로 범용 계산을 제공하지 않습니다. 공식 표 조회 테스트 통과가 계리 엔진 재현 검증이나 보험사 인증을 의미하지 않습니다.
