# jw_financial_tools

고객 상담용 금융 시뮬레이터 및 계산 도구 모음입니다.

## 메트라이프 변액리치정기보험 시뮬레이터

[시뮬레이터 열기](./metlife-variable-term.html) · [추정 방법·출처·검증 범위](./docs/metlife-variable-term.md)

**상담 예시용 추정형 v0.4**입니다. 출생연도·성별·일반/간편·보험료/가입금액·추가납입 0/50/100%·전환시점·전환 전후 수익률(-1~20%)에 따라 즉시 계산합니다. 보험료와 가입금액을 연결하고, 초회 최저보험료 이후 정기납입을 중단한 적립형의 사망보험금·해약환급금·환급률을 예시합니다. 7·8·9·10년 전환 비교, 연도별 표, 인쇄를 지원합니다.

보험사 산출방법서를 복원한 계리 엔진이 아닙니다. 일반형 40세 설계서로 합산 비용을 보정했으며 다른 나이·금액·전환시점·수익률은 확장 추정입니다. 간편형 비용은 전용 설계서 보정 전의 임시 추정입니다. 실제 금액 및 가입·전환 가능 여부는 보험사 가입설계로 확인해야 합니다.

브라우저에서 단일 HTML만 열면 동작하며 외부 서비스에 고객 입력을 전송하지 않습니다. 기존 공식 예시 조회·CSV·수동 비용 연구 도구는 하단 접힌 영역에 유지합니다.

```sh
node scripts/build-metlife.mjs
node --test tests/*.test.cjs
node scripts/verify-metlife-calibration.cjs
```
